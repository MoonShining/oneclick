# windows平台语音包应用

使用golang实现, 用户界面使用fyne, 音频播放使用oto

核心功能：
1. 将sounds文件夹中的音频预先加载到应用中, 通过2层列表ui展示, 不需要任何编辑功能
- 第一层是目录名称列表，第二层是音效名称列表
- 单击音效名称列表选中，默认选中第一个列表中的第一个音频
- 双击音效名称列表可以播放对应的音频, 使用系统默认设备播放
- 支持拖拽音效到轮盘，轮盘会持久化保存当前音效，用于后续播放

2. 轮盘
- 默认空白，等待用户设置
- 支持自定义游戏中显示轮盘快捷键, 默认是P, 支持游戏全屏时显示，轮盘无边框，无背景
- 按住快捷键显示轮盘，松开快捷键关闭轮盘，松开时判断鼠标是否在轮盘上，若在轮盘上则播放鼠标所在位置的音频到Cable Input设备
